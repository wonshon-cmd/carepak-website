# carepakpharmacy.com

The Carepak Pharmacy website. Plain HTML/CSS/JS on GitHub Pages; no build step.

| File | What it is |
|---|---|
| `index.html` | Home page |
| `style.css` | Styling and phone layouts |
| `app.js` | Mobile menu and the provider/employee portal previews |
| `showcase.html` | Redirect for old links → start.carepakpharmacy.com/letsconnect |

- **Let's talk / Let's connect** → https://start.carepakpharmacy.com/letsconnect/ (submissions go to the owner dashboard).
- **Onboarding** → https://carepak-onboarding.onrender.com/contractor (real onboarding; needs an invitation code).
- **Provider / Employee portals** are previews only (demo codes `CPK-PROVIDER-DEMO`, `CPK-EMPLOYEE-DEMO`). No accounts or records.

Design: from the "Carepak Pharmacy | Care, connected." redesign package. Fonts: Barlow + Inter (Google Fonts).
